# Bio Radar

**Yerel sunum:** `./run.sh` API’yi ve Linux uygulamasını birlikte açar; 30 açıkça etiketli demo kayıt kullanır. Giriş bilgileri terminalde gösterilir. `./run.sh --api-only` yalnız API’yi başlatır.

Ecological intelligence & decision-support platform for **Kastamonu, Türkiye**: citizens record wildlife / plant / water / forest / pollution
observations with photo + location → AI suggests (never verifies) → reviewers verify → everything is shown on a map, queryable through a
geo-aware RAG assistant, enriched with official announcements and used for deterministic climate/drought what-if analysis.

Status: under active development (hackathon start, built to be maintained). See `handoff.md` for the current state and
`BUG_REPORT.md` for open issues.

## Repository layout
```
backend/            Go API server (net/http + SQLite/sqlite-vec/FTS5/RTree)
apps/flutter_app/   Flutter client (Linux, Windows, Android, iOS, Web)
docs/               API contract (docs/api/openapi.yaml), architecture, data sources, simulation
datasets/           seed, geographical and environmental data with provenance
scripts/            helper scripts (e2e)
```

## Requirements
- Go 1.27+ and a C compiler (gcc/clang; MinGW-w64 on Windows) — the backend uses CGO for SQLite + sqlite-vec.
- Flutter 3.44+ (Dart 3.12+). Linux desktop needs the usual GTK toolchain (`flutter doctor`).
- No Docker, no external vector DB, no Python.

## Run (development)
```bash
cp .env.example .env            # set ECO_ADMIN_EMAIL / ECO_ADMIN_PASSWORD; AI keys are optional
set -a; source .env; set +a     # export runtime settings
cd backend && make run          # http://localhost:8080/api/v1/health
cd apps/flutter_app && flutter run -d linux --dart-define=API_BASE_URL=http://localhost:8080/api/v1
```
Without AI configuration everything except generated prose / photo suggestions still works (map, observations, review, FTS retrieval, simulation).

## Test
```bash
cd backend && make vet && make test      # go vet + go test -race
cd apps/flutter_app && flutter analyze && flutter test
./scripts/e2e.sh                         # against a running backend
```

## Platform support (honest status)
Verified on Linux (backend + Linux desktop app). Windows, macOS, iOS, Android and Web targets are generated by Flutter but are
**not built/tested** in the current development environment.
